# Task 1 – Exception Handling

## Objective

Demonstrates input validation, try-catch, multi-catch and finally using a simple ATM withdrawal example.

## Program

`Task1.java`

## Description

The program accepts a withdrawal amount, checks that it is positive and does not exceed the sample balance, and displays the remaining balance. It also handles non-numeric input.

## Requirements

- JDK 17 or later
- Java compiler (`javac`)

## Compile and run

Run these commands from the repository root:

```bash
javac Task1.java
java Task1
```

## Expected behavior

Try a valid amount, a negative amount, an amount above 5000, and non-numeric input.

## Result

The program demonstrates the concepts listed above. Run it and capture the actual console output for your assignment record.
