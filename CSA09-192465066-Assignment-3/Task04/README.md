# Task 4 – Thread Life Cycle

## Objective

Demonstrates Runnable, Thread, start(), sleep() and join().

## Program

`Task4.java`

## Description

Creates four scanner station threads. Each thread simulates scanning and the main thread waits until all stations finish.

## Requirements

- JDK 17 or later
- Java compiler (`javac`)

## Compile and run

Run these commands from the repository root:

```bash
javac Task4.java
java Task4
```

## Expected behavior

The station messages may appear in a different order because the threads execute concurrently.

## Result

The program demonstrates the concepts listed above. Run it and capture the actual console output for your assignment record.
