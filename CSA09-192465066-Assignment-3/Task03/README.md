# Task 3 – File Handling with Try-with-Resources

## Objective

Demonstrates reading and writing files and automatic resource management using try-with-resources.

## Program

`Task3.java`

## Description

Reads sales entries from sales.txt, calculates the total and writes the formatted result to report.txt. A sample input file is created if one is not present.

## Requirements

- JDK 17 or later
- Java compiler (`javac`)

## Compile and run

Run these commands from the repository root:

```bash
javac Task3.java
java Task3
```

## Expected behavior

Run the program and inspect report.txt in the working directory. Edit sales.txt to test other values.

## Result

The program demonstrates the concepts listed above. Run it and capture the actual console output for your assignment record.
