# Task 6 – Producer-Consumer using wait and notifyAll

## Objective

Demonstrates inter-thread communication with a bounded buffer, wait() and notifyAll().

## Program

`Task6.java`

## Description

A producer places 20 tokens into a shared buffer while two consumer threads collect them. The program displays the sum of all collected token values.

## Requirements

- JDK 17 or later
- Java compiler (`javac`)

## Compile and run

Run these commands from the repository root:

```bash
javac Task6.java
java Task6
```

## Expected behavior

The final sum should be 210.
