# Task 5 – Synchronization

## Objective

Demonstrates synchronized methods to prevent race conditions during seat booking.

## Program

`Task5.java`

## Description

Many booking threads attempt to book ten seats. Synchronization ensures each seat is booked only once.

## Requirements

- JDK 17 or later
- Java compiler (`javac`)

## Compile and run

Run these commands from the repository root:

```bash
javac Task5.java
java Task5
```

## Expected behavior

The final output should report Seats sold: 10.
